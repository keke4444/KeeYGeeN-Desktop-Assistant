# dtidy 终端界面规范（TUI-SPEC）

> 版本：v0.2 ｜ 配套文档：[PRD.md](PRD.md)、[DESIGN.md](DESIGN.md)、[CATEGORY-RULES.md](CATEGORY-RULES.md)
> 适用范围：**可选终端版 `dtidy-tui.exe`**。GUI 是默认交付形态（见 DESIGN §13），本文件描述终端版的界面与按键。
> 分类来源：`<桌面>\home` 下的子文件夹（见 CATEGORY-RULES.md），底部目标目录显示为 `…\home\<分类>\`。
> 布局形态：**单栏列表 + 快捷键**

---

## 1. 界面布局

```
┌─ Ubuntu 桌面整理 ───────────────────────────────────────────────┐   ← 标题栏（Aubergine 底 + 橙字）
│ 桌面: C:\Users\you\Desktop                                     │   ← 环境行（灰字）
│ 目标分类: ◀ 工具 (2/5) ▶   [Tab] 切换  [1-5] 直选  [c] 单项指定  │   ← 分类行（当前分类高亮橙）
├────────────────────────────────────────────────────────────────┤
│    ida64.exe.lnk                 3.2 MB                         │
│  ● CheatEngine.lnk               1.1 MB                         │   ← 已标记（● 橙）
│  ▸ 屏幕截图_20261020.png         856 KB                         │   ← 光标行（▸ + Aubergine 反色）
│    会议录屏.mp4                  340 MB                         │
│    backup.tar.gz                  12 MB                         │
│  ◆ README                                                       │   ← 无扩展名（◆）
│                                                                 │
├────────────────────────────────────────────────────────────────┤
│ 选中 屏幕截图_20261020.png · 856 KB · 修改 2026-10-19 21:04      │   ← 详情行（窄终端可隐藏）
│ 已标记 2 项 / 共 6 项 · 目标目录: …\Desktop\工具\                │
├────────────────────────────────────────────────────────────────┤
│ Space 标记  Enter 移动  Tab 切分类  c 改分类  r 重扫  ? 帮助  q 退出 │   ← 快捷键提示行（橙底白字）
└────────────────────────────────────────────────────────────────┘
```

> 分类行里的分类 = **桌面上已有的一级文件夹**（按名称排序）+ 配置里补充的分类名。工具只读取这些文件夹的名字作为分类，不会移动、改名或删除它们本身。

### 行分配（不随终端高度浮动）
| 区域 | 行数 | 说明 |
|---|---|---|
| 标题栏 | 1 | 固定 |
| 环境行 | 1 | 桌面路径，超长时中部省略为 `…` |
| 分类行 | 1 | 固定 |
| 列表区 | 自适应剩余 | 光标超出可视区时滚动，保持光标居中 |
| 详情行 | 2 | 终端高度 < 18 行时隐藏 |
| 快捷键行 | 1 | 固定 |

### 图标语义（颜色 + 符号双通道，不依赖颜色区分状态）
| 符号 | 含义 |
|---|---|
| `▸` | 当前光标行 |
| `●` | 已标记待移动 |
| `◆` | 无扩展名文件（仅标注提示） |
| `!` | 该条目不适合移动（目录 / 符号链接 / 超长路径），并在详情行给出原因 |

## 2. 按键表

### 2.1 列表状态（主状态）

| 按键 | 动作 |
|---|---|
| `↑` / `k` | 光标上移 |
| `↓` / `j` | 光标下移 |
| `g` / `G` | 跳到首项 / 末项 |
| `Ctrl+u` / `Ctrl+d` | 上翻半页 / 下翻半页 |
| `Tab` / `Shift+Tab` | 目标分类后移 / 前移（循环） |
| `1`–`9` | 直接切换到第 N 个分类 |
| `Space` | 标记 / 取消标记光标项 |
| `a` | 全选 / 取消全选 |
| `c` | 为光标项单独指定目标分类（弹出分类浮层，覆盖分类行当前选中的分类） |
| `Enter` | 执行移动（有标记 → 移动全部标记项；无标记 → 移动光标项） |
| `r` | 重新扫描桌面 |
| `/` | 过滤输入（v0.1 可选实现） |
| `?` | 打开帮助浮层 |
| `q` / `Ctrl+c` | 退出（移动进行中禁用） |

### 2.2 浮层状态

| 浮层 | 按键 | 动作 |
|---|---|---|
| 确认移动 | `y` / `Enter` | 确认执行 |
| | `n` / `Esc` | 取消返回列表 |
| 分类选择 | `↑↓` / `jk` | 选择分类 |
| | `Enter` | 应用并返回 |
| | `Esc` | 取消 |
| 帮助 | `?` / `Esc` / `q` | 关闭 |
| 结果报告 | `d` | 展开/收起失败明细 |
| | `Enter` / `Esc` | 关闭，回到列表 |
| 进度中 | `Ctrl+c` | 中止（已完成的条目保持完成状态，写入日志） |

**保留**：移动/撤销进行中只接受 `Ctrl+c`，其余按键忽略，防止状态竞争。

## 3. 状态机

```
        ┌──────────┐
        │  Boot    │ 解析桌面/加载配置（失败 → Error）
        └────┬─────┘
             ▼
        ┌──────────┐  r
        │ Scanning │◀────────────┐
        └────┬─────┘             │
             ▼                   │
   ┌──────────────────┐          │
   │      List        │──────────┘
   └──┬────┬────┬───┬─┘
      │    │    │   │
  Enter  c   ?   q
      │    │    │   └──▶ Exit（写会话汇总，打印日志路径）
      │    │    └──────▶ Help ──(Esc/?)──▶ List
      │    └───────────▶ CategoryPick ──(Enter/Esc)──▶ List
      ▼
  ┌──────────┐   y    ┌──────────┐  完成  ┌──────────┐
  │ Confirm  │───────▶│ Progress │───────▶│  Report  │──(Enter)──▶ List
  └────┬─────┘        └────┬─────┘        └──────────┘
       │ n/Esc             │ Ctrl+c
       └──────▶ List       └──────▶ Report（部分完成）
```

`Scanning` 期间列表区显示 Ubuntu 风格的点状/脉冲进度（`⠋⠙⠹⠸⠼⠴⠦⠧⠇⠏` 一类的 Braille 动画），不显示空白。

## 4. 关键交互细节

### 4.1 确认浮层文案（必须列明「去哪」）
```
┌─ 确认移动 ─────────────────────────────────────┐
│  将移动 3 个文件 (2.1 MB)                      │
│  目标目录: …\Desktop\工具\                     │
│  ├ 屏幕截图_20261020.png                       │
│  ├ 头像.jpg                                    │
│  └ 设计稿.psd                                  │
│  [y] 确认   [n] 取消                            │
└────────────────────────────────────────────────┘
```
- 目标目录始终显示**绝对路径**（超长时中部省略，但保留盘符与末级目录）。
- 超过 5 个文件时列表折叠为「前 5 个 + 其余 N 个」。
- 若配置了 `confirm_above_mb` 且存在超限文件，浮层额外用橙色行提示：「含 1 个体积 > 500 MB 的文件」。

### 4.2 进度
- 单文件：`[████████░░░░░░] 62%  屏幕截图_20261020.png → 工具\`
- 多文件：追加第 2 行 `已完成 2/3 · 跳过 0 · 失败 0`
- 校验阶段显示 `校验中（sha256）`，避免用户误以为卡死。

### 4.3 报告
```
┌─ 移动结果 ────────────────────────────────────┐
│  成功 3   跳过 1   失败 0                     │
│  ── 跳过明细（按 d 展开）──                   │
│  backup.tar.gz: 目标已存在同名文件             │
│  [Enter] 返回列表                              │
└───────────────────────────────────────────────┘
```
- 失败条目必须带原因文案（映射自 DESIGN §7.2 失败矩阵），不使用裸错误字符串。

### 4.4 空状态与错误态
- 空桌面：`桌面很干净，没有需要整理的文件  (r 重新扫描 · q 退出)`
- 分类列表为空：分类行显示 `目标分类: （暂无分类）`，按 Enter 提示 `桌面上还没有分类文件夹，先建一个（或写进 config 的 extra_categories）`，不执行移动。
- 桌面解析失败：整屏错误面板，显示尝试过的候选路径与解决建议（「请在 config.toml 中手动指定 desktop」）。

## 5. 响应式与终端适配

| 终端宽度 | 调整 |
|---|---|
| ≥ 100 列 | 显示完整文件名 + 大小 |
| 80–99 列 | 文件名截断（保留扩展名），大小保留 |
| < 80 列 | 隐藏大小列，分类信息只靠分类行；快捷键提示改短版 `Space/Enter/Tab/c/?/q` |
| 高度 < 18 行 | 隐藏详情行两行，仅保留列表 + 快捷键行 |

- 所有宽度计算基于 `lipgloss.Width`（按显示宽度而非字节数），确保中文文件名对齐。
- 中文字符宽度按 2 计算，截断时保证不切断多字节字符。

## 6. 配色令牌（Ubuntu 品牌色）

| 令牌 | 十六进制 | 用途 | 256 色降级 |
|---|---|---|---|
| `primary`（Aubergine） | `#772953` | 光标行背景、标题栏背景 | 96 |
| `primary-dark` | `#5E2750` | 光标行交替、分隔线 | 95 |
| `accent`（Ubuntu Orange） | `#E95420` | 当前分类、标记符号、快捷键行背景、强调数字 | 202 |
| `accent-light` | `#F0873A` | 悬停/次强强调 | 209 |
| `text` | `#F2F2F2` | 主文本（深色底） | 255 |
| `text-muted`（Warm Grey） | `#AEA79F` | 次要信息（大小、路径） | 145 |
| `danger` | `#C7162B` | 失败、错误 | 160 |
| `success` | `#0E8420` | 成功计数 | 34 |
| `bg` | 终端默认背景 | 不主动设置背景色 | — |

规则：
- 深色终端为前提设计；浅色终端不做专门适配（v0.1），但所有前景色需在两种底色下可读（避免纯黑/纯白文字）。
- 真彩检测：`lipgloss.Color` 支持 truecolor 时输出十六进制，否则使用上表 256 色索引。
- 颜色不可单独承载语义（见 §1 图标语义）。

## 7. 组件与实现要点（Bubble Tea）

- `tui.Model` 持有：`entries []fsops.Entry`、`cursor int`、`catIndex int`、`marked map[string]bool`、`state State`、`overlay`、`progress`、`report`、`width/height`。
- 使用 `bubbles/viewport` 或自算窗口偏移渲染列表；不引入 `bubbles/list`（其默认样式与 Ubuntu 视觉冲突，定制成本更高）。
- 移动执行放在 `tea.Cmd` 中异步跑，通过 `tea.Msg` 回传进度与结果；`Update` 不阻塞。
- `View` 为纯函数，无副作用、无 IO，便于按 SPEC 逐条对照验收。
- 窗口尺寸变化用 `tea.WindowSizeMsg` 存储，`View` 每帧按 §5 规则重排。
