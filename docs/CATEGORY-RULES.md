# dtidy 分类规则（CATEGORY-RULES）

> 版本：v0.2 ｜ 配套文档：[PRD.md](PRD.md)、[DESIGN.md](DESIGN.md)、[TUI-SPEC.md](TUI-SPEC.md)
> 核心约定：`<桌面>\home\<分类>\`，分类由用户创建，工具不做自动归类。

---

## 1. 分类从哪来

| 来源 | 开关 | 说明 |
|---|---|---|
| `home` 下的子文件夹 | `discover_categories = true`（默认开） | `home\工具`、`home\编程` 等目录自动成为分类 |
| 配置补充 | `extra_categories = ["取证", "repwn"]` | 桌面上还没有时，移动前按需创建 |
| 排除 | `exclude_categories = ["临时"]` | `home` 里存在但不作为分类 |
| 界面新建 | 左侧栏 `+` | 直接在 `home` 下创建目录 |

**不包含**：桌面上的其它文件夹、桌面上的文件、扩展名自动判定、内容识别。
因此桌面上原有的一堆项目文件夹（`AI审计`、`QvQ`…）不会再冒充分类。

## 2. 分类名 = 文件夹名

- 左栏显示的名字就是 `home` 下的目录名。
- 不支持嵌套分类：类别名不能含 `/`、`\`。
- 大小写按 Windows 语义不敏感，展示保留用户写法。

## 3. 命名合法性（创建/加载时校验）

按「Windows 建文件夹」规则：

| 规则 | 违规示例 |
|---|---|
| 非空、≤ 255 字符 | `""` |
| 不含 `<` `>` `:` `"` `/` `\` `|` `?` `*` | `re/pwn`、`工具?` |
| 不以空格或 `.` 结尾 | `工具 .`、`编程.` |
| 不是保留名 `CON` `PRN` `AUX` `NUL` `COM1`-`COM9` `LPT1`-`LPT9` | `con`、`nul` |
| 与已有分类不重复（不区分大小写） | `工具` 与 `工具` |

违规处理：**直接报错并提示具体原因，不静默改名、不跳过**。

## 4. 什么可以被移动

| 对象 | 可移动 | 说明 |
|---|---|---|
| 普通文件 | 是 | 可拖拽、可多选 |
| `.lnk` / `.url` | 是 | 移动快捷方式本身不改变其绝对路径指向 |
| 无扩展名文件 | 是 | 表格「类型」显示为「文件」 |
| 文件夹 | 否 | 拖拽无效；文件夹不是整理对象 |
| `.dtidy-tmp-*` 残留 | 否 | 上次异常退出的临时文件，不会出现在列表 |
| `desktop.ini` / `Thumbs.db` / `.DS_Store` | 否 | 系统文件，扫描时忽略 |
| 隐藏文件 | 否 | `show_hidden = true` 时才列出 |

## 5. 移动动作

- 目标：`<桌面>\home\<分类>\`（或桌面本身，用于移回）。
- 目录不存在 → 按需创建；已存在 → 直接复用。
- 重名 → `conflict` 策略（默认 `index`：`a (2).png`），永不覆盖。
- 完整链路与失败处理见 [DESIGN.md](DESIGN.md) §7。

## 6. 示例

| 操作 | 结果 |
|---|---|
| 桌面 `CTF新手村.pdf` → 拖到「工具」 | `C:\Users\you\Desktop\home\工具\CTF新手村.pdf` |
| 桌面 `ChatGPT.lnk` → 拖到「工具」 | `C:\Users\you\Desktop\home\工具\ChatGPT.lnk`，双击仍可启动 |
| 分类「文档」里 `a.png` → 拖回「桌面」 | 回到 `C:\Users\you\Desktop\a.png` |
| 桌面文件夹 `AI审计` | 不作为分类、不能被移动 |
| 在 `home` 下手工建 `取证\` | 下次刷新即出现在左栏 |
| 新建分类输入 `re/pwn` | 报错：含非法字符 `/`，不创建目录 |

## 7. 维护约定

- 加分类：左栏 `+`，或直接在 `home` 下建文件夹。
- 不想让某个 `home` 子目录当分类：写进 `exclude_categories`。
- 工具永不移动/删除分类目录本身。
- 分类改名不会迁移历史文件；需要重整就撤销后重新移动。
- 扩展名自动分类属于后续可选项（见 PRD §10）。
