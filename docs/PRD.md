## 1. 背景与问题

桌面是临时的「暂存区」：下载文件、截图、临时导出的表格、别人发来的压缩包全堆在桌面，几周后成一锅粥。用户找不到东西，又不敢随手删——因为大多只是「暂时不知道放哪」，并不是没用。

`dtidy` 解决的不是「清理」而是「归位」：

- 不删除任何用户文件，只把文件从桌面移动到分类文件夹里。
- 用户随时知道文件去哪了（固定目录结构 + 操作日志 + 可撤销）。
- 界面是 **Windows 图形窗口**，同时提供终端 TUI 版本。

**与「桌面收纳面板」类工具的差别**：Maye Lite 一类工具只把快捷方式**登记**进虚拟面板，文件本体还堆在桌面上——面板再整齐，桌面照样乱。`dtidy` 做的是**真实移动**：文件确实被移走，桌面真的变干净；分类文件夹就是普通目录，资源管理器随时能打开。

## 2. 目录模型（2.0）

把**桌面本身当作 `/home`**，在桌面下建一个 `home` 作为整理根，分类全部放在 `home` 里：

```
<桌面>\
├── home\                  ← 整理根（root_dir = "home"）
│   ├── 工具\              ← 分类（用户自建）
│   ├── 编程\
│   └── 取证\
├── 随手放的截图.png        ← 待整理文件
└── 项目资料\              ← 用户自己的文件夹，不参与分类
```

- **分类只认 `home` 下的子文件夹**：桌面上的其它文件夹（如「项目资料」）不会被当成分类。
- **分类由用户创建**：界面左侧 `+` 新建，或在 `home` 下直接建文件夹；不预置任何默认分类。
- **分类名 = 文件夹名**，遵循 Windows 建文件夹规则；非法名直接报错，不做改名映射。
- **全程不删除用户文件**：移动链路是「复制 → 校验 → 重命名到位 → 删源」；文件夹永不被移动。

## 3. 目标（v0.2）

| 编号 | 目标 |
|---|---|
| G-1 | 提供 Windows 图形界面（Wails + WebView2），像文件管理器一样浏览桌面与 `home` |
| G-2 | 零删除：源文件只在目标副本校验通过后才删除 |
| G-3 | 目录结构稳定可预期：`<桌面>\home\<分类>\`，分类由用户创建 |
| G-4 | 每次移动可追溯、可撤销：JSONL 日志 + 撤销按钮 |
| G-5 | 保留终端 TUI 版本（`dtidy-tui.exe`），两个前端共用同一套核心逻辑 |

## 4. 非目标

- 不做内容/语义识别分类，不调用 AI。
- 不做扩展名自动分类（全部由用户选分类）。
- 不删除、不清空回收站、不清理系统垃圾。
- 不移动文件夹、不递归整理。
- 不做后台常驻、文件监听、定时任务。
- 不做云同步、不联网、不含遥测。
- Linux / macOS 版本暂不交付（`platform` 层已留抽象）。

## 5. 用户与场景

**目标用户**：桌面长期堆积文件的开发者/办公用户，习惯 Windows 资源管理器。

1. 场景 A：桌面 60 个下载文件 → 左侧新建「工具」「文档」两个分类 → 全选拖到分类上 → 桌面只剩 `home` 和自己的文件夹。
2. 场景 B：发现归错了 → 点「撤销上一步」→ 文件回到桌面原位置。
3. 场景 C：想看看某分类里有什么 → 左栏点分类 → 右侧表格列出内容，可拖回桌面。

## 6. 术语

| 术语 | 含义 |
|---|---|
| 桌面 | 平台语义的用户桌面，Windows 经注册表 `User Shell Folders` 解析 |
| home（整理根） | `<桌面>\home`，所有分类的父目录，由 `root_dir` 配置，首次启动自动创建 |
| 分类 | `home` 下的一个子文件夹，例如 `<桌面>\home\工具` |
| 移动 | 复制 → 校验 → 重命名到位 → 删除源文件 |
| 撤销 | 按批次把已移动文件搬回原位置，同样走完整校验链路 |

## 7. 功能需求

### FR-1 启动与环境
- 解析桌面真实路径（注册表优先），窗口顶栏展示。
- 首次启动自动创建配置目录、`config.toml` 与 `<桌面>\home`。
- 桌面/`home` 不可访问时弹出错误提示，不进入主界面。

### FR-2 浏览
- 左侧栏：`桌面`、`home`、分类列表（每个显示文件数）。
- 右侧表格：名称、类型、大小、修改时间；目录在前、文件在后。
- 面包屑导航；`↑` 返回上级；双击目录进入、双击文件用默认程序打开。
- **两种视图可切换**：图标视图（上面图标、下面文字，类似资源管理器的“大图标”）与详情列表（名称/类型/大小/修改时间）；切换结果记住，下次启动沿用。
- **Ctrl + 滚轮**在文件区缩放图标（60%–200%），缩放值写入配置并记住。
- 刷新（F5）重新读取目录与分类。

### FR-3 分类管理
- `+` 新建分类：输入名字 → 在 `home` 下创建目录 → 立即出现在左栏。
- 分类名按 Windows 文件夹规则校验（非法字符、保留名、结尾空格/点），违规即报错。
- 分类列表 = `home` 下的子文件夹 + 配置补充项（去重、排序稳定）。
- 支持删除？**不做**（删除属于危险操作，请在资源管理器手动处理）。

### FR-4 移动
- 拖拽：选中文件拖到左栏的 `home`、分类或 `桌面` 节点上松手即移动。
- 按钮：选文件 → 「移动到…」→ 选择目标分类。
- 右键菜单：移动到分类 / 移回桌面 / 在资源管理器中显示。
- 只允许移动**普通文件**；目标只能是桌面或 `home` 内部。
- 目标已存在同名文件时按 `conflict` 策略处理（默认 `index` → `a (2).png`），永不覆盖。
- 移动成功后刷新两侧列表并显示结果汇总。

### FR-5 撤销
- 按批次撤销最近一次移动，每个文件同样走「复制 → 校验 → 删源」。
- 目标不存在或源位置已被占用时跳过并给出原因，绝不覆盖。

### FR-6 日志
- 每次移动/撤销写一行 JSONL：时间、批次、动作、源、目标、大小、SHA256、结果。
- 日志路径在配置目录，界面底部展示配置文件与版本信息。

### FR-7 视觉
- Ubuntu 风格：Aubergine `#772953` 深色底 + Ubuntu Orange `#E95420` 强调色。
- **文件图标使用 Windows 系统真实图标**（Shell API `SHGetFileInfo` 提取，PNG 内嵌），失败时回退到内置矢量图标。
- **图片文件显示缩略图**（png/jpg/gif/bmp/webp/ico/tiff）：等比缩放到长边 80px 后内嵌，穷举失败（如 0 字节文件）回退到类型图标。
- 选中态、拖拽目标高亮、空状态、错误提示均有明确文案。
- 信息不只靠颜色传达（选中行同时有左侧色条）。

### FR-8 设置面板
- 入口：工具栏齿轮按钮。
- **召唤热键**：自定义全局热键（如 `Ctrl+Alt+D`），按一次显示主窗口并置前，再按一次隐藏窗口（最小化时直接唤回）；注册失败（被占用/格式错误）会明确提示。
- **DIY 背景**：选择本机图片作为文件区背景（png / jpg / gif / webp / bmp），**gif / webp 动图保留动画**；可调透明度（5%–100%）；可一键清除。
- **分类栏位置**：左侧 / 右侧 / 顶部 三种布局，立即生效并记住。
- **图标大小**：滑杆 60%–200%，与 Ctrl+滚轮联动。
- 所有设置写入 `config.toml`，下次启动自动恢复。

## 8. 验收标准

- AC-1 启动后窗口显示正确桌面路径，且 `<桌面>\home` 被自动创建。
- AC-2 左侧「分类」只显示 `home` 下的子文件夹，桌面上的其它文件夹不出现。
- AC-3 新建分类「工具」→ `home\工具` 存在并出现在左栏。
- AC-4 桌面选中 `a.png` 拖到「工具」→ `home\工具\a.png` 存在，桌面 `a.png` 消失。
- AC-5 目标已有 `a.png` 时再移动 → 生成 `a (2).png`，原文件内容不变。
- AC-6 进入分类目录可看到刚移动的文件，可拖回桌面。
- AC-7 校验失败（注入故障）时源文件仍在桌面，目标目录无临时文件残留。
- AC-8 点「撤销上一步」→ 文件回到桌面，分类里的副本消失。
- AC-9 分类名输入 `re/pwn` → 报错，不创建任何目录。
- AC-10 文件夹不能被移动（拖拽无效），且不参与分类列表。

## 9. 已确认决策

| 议题 | 结论 |
|---|---|
| 产品定位 | 真实移动文件的桌面归类器，不是虚拟收藏面板 |
| 界面形态 | Windows 图形窗口（Wails + WebView2），左栏目录树 + 右侧文件区；分隔条可拖动调整侧栏宽度 |
| 侧栏文件夹 | 「打开文件夹」把目录加入侧栏（持久化），右侧 × 仅关闭不删除；支持右键自定义图标 / 重命名 / 指定文件夹 / 移除 |
| 搜索 | 左栏顶部搜索框，递归匹配文件名；范围默认「当前文件夹」（文件目录与分类均生效），可切换「全局」（桌面/home/已打开文件夹） |
| 右键菜单 | 文件区使用 Windows 原生右键菜单（与资源管理器一致，含第三方扩展项）：文件行弹出选中文件/文件夹的菜单，空白处弹出当前文件夹的背景菜单（新建 / 查看 / 排序 / 第三方扩展等） |
| 侧栏删除 | 分类右键「删除分类…」会删除该文件夹及其中文件，删除前必须二次确认；已打开文件夹的 × 仅关闭不删除 |
| 搜索候选 | 输入后按 Tab 唤出候选下拉，一次显示 3–30 条（可继续滚动查看全部结果），↑↓ 或 − + 切换、Enter 打开，高亮跟随整体颜色 |
| 候选规则 | 可选规则文件（txt/json/csv/tsv/ini/toml），支持排除词与优先词，实时作用于搜索结果 |
| 视图 | 图标视图 / 详情列表两套视图，可切换并记忆 |
| 图标 | 真实 Windows 文件图标（48×48 系统超大图标，失败回退 32×32 与矢量图标） |
| 缩略图 | 图片文件优先显示缩略图（长边 160px，Go 原生解码 + 等比缩放），解码失败回退类型图标 |
| 缩放 | Ctrl+滚轮与设置滑杆调整图标大小（60%–200%），持久化 |
| 热键 | 全局热键切换窗口显示/隐藏（RegisterHotKey），可自定义 |
| 产品名称 | KeeYGeeN桌面助手：窗口标题、侧栏品牌、可执行文件、桌面快捷方式与安装包同名；应用图标统一使用 KeeYGeeN 战队 logo |
| 安装交付 | Inno Setup 安装包 `KeeYGeeN桌面助手-Setup.exe`，可选创建桌面快捷方式，卸载时移除程序目录。正式版不带任何预设图片，安装目录只有 exe；发给姐姐的第二版 `KeeYGeeN桌面助手2-Setup.exe` 额外附带 `bg.png` 预设壁纸（蓝色主题、90% 透明度、铺满） |
| 背景 | 支持自定义图片背景 + 透明度 + gif/webp 动图，适配方式可选完整显示/铺满/拉伸/平铺；作用域可选全局 / 仅文件区（跟随侧边栏）/ 拉选矩形。仅第二版（编译期开启 `UseDefaultBg`）会自动读取 exe 同目录的 `bg.png` 作为初始背景；正式版即使同目录存在 `bg.png` 也不会加载 |
| 路径设置 | 设置里可选择桌面目录与 home 目录；所选文件夹不叫 home 时提示在其中创建 home |
| 开机启动 | 可选写入 HKCU\Software\Microsoft\Windows\CurrentVersion\Run |
| 托盘图标 | 程序启动即在任务栏通知区域（右下角小图标区）显示 KeeYGeeN 图标：左键单击切换主窗口显示/隐藏，右键菜单提供「显示主窗口」「退出程序」；资源管理器重启后自动恢复图标 |
| 关闭行为 | 可勾选「关闭窗口时隐藏到系统托盘」：点 × 只隐藏窗口不退出，程序留在托盘小图标里，单击托盘图标或热键可再次唤出；取消勾选则正常退出 |
| 配色 | 整体颜色作用于整个界面（底色与强调色），页面颜色可作为单独覆盖；返回上一级按钮可跟随整体色或单独设色；设置弹窗颜色与界面保持一致，随页面颜色实时联动 |
| 分类栏位置 | 左 / 右 / 顶 三选一 |
| 目录结构 | `<桌面>\home\<分类>`；`home` 为整理根，分类由用户创建 |
| 分类来源 | 仅 `home` 下的子文件夹 + 配置补充；不预置、不自动判定、不把桌面文件夹当分类 |
| 最近 | 侧栏「桌面」上方新增「最近」入口；记录本程序内双击打开的文件，也记录在系统（资源管理器等）里打开的文件（1 秒级轮询系统「最近使用」目录，解析 .lnk 目标）；同一路径合并为一条并累加次数，显示最近打开时间与次数；只保存路径，不复制、不移动任何文件 |
| 最近任务分组 | 任务标签（默认最近 / 任务…）位于路径栏下方单独一行，胶囊样式；「＋ 新建任务」放在上方路径栏。任务可新建、重命名、删除（不创建任何文件夹）；记录可拖动到其它任务，移出「默认最近」后不再显示；任意分组内删除记录只删记录，不删除原文件；删除任务时组内记录回到「默认最近」。标签颜色可在设置中单独指定，或勾选「跟随整体颜色」 |
| 任务标签配色 | 设置里「任务标签颜色」与「返回上一级按钮」一致：默认勾选跟随整体颜色，取消勾选后才显示取色器，颜色持久化到 `theme_recent` / `follow_recent` |
| 字体 | 设置里可配置全局字体（系统默认/微软雅黑/等线/宋体/黑体/楷体/仿宋/Consolas/Segoe UI）、字号（10–24px）与文字颜色（可跟随主题）；并支持按分区单独覆盖：侧栏、路径栏与任务标签、文件区、设置弹窗，每个分区可单独设置字体、字号、颜色，留空/勾选继承则沿用全局。配置持久化到 `font_*` 与 `[font_parts.*]` |
| 分类命名 | 即文件夹名，按 Windows 规则校验，非法直接报错 |
| 安全策略 | 复制 → 校验 → 重命名 → 删源；永不覆盖；文件夹不动 |
| 撤销 | 按批次撤销，同样走校验链路 |
| 快捷方式 | `.lnk` / `.url` 作为普通文件参与移动，移动后仍可用 |
| 终端版 | 保留 `dtidy-tui.exe`，与 GUI 共用核心逻辑 |
| 技术栈 | Go + Wails v2.17 + 原生 HTML/CSS/JS（无构建步骤） |

## 10. 后续可选项

1. 扩展名建议分类（如 `.png` → 图片），仅作为提示。
2. 大文件移动前二次确认（`confirm_above_mb` 已预留）。
3. 分类内二级归档（按日期/项目）。
4. Linux / macOS 版本。
5. `.lnk` 目标解析（避免移动目标文件导致快捷方式断链）。
